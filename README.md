# Мой чат

Автор и правообладатель: top4k155 Код написан автором.

Небольшой закрытый чат для группы участников. Вход через Google или Яндекс, общие сообщения в реальном времени, отправка файлов до 20 МБ, уведомления в браузере и админ-панель для списка участников.

## Что умеет

- **Вход**: через Google (Firebase Authentication) или Яндекс ID. Вход с Яндексом проверяется на сервере.
- **Доступ по списку**: писать и читать может только почта из списка участников. Список ведётся в админ-панели.
- **Сообщения** в реальном времени, закрепление сообщения (только владелец), удаление своих сообщений.
- **Файлы** до 20 МБ. Скачивание по временной подписанной ссылке.
- **Уведомления** о новых сообщениях через Firebase Cloud Messaging (Web Push).
- **Настройки**: светлая и тёмная тема, формат времени 12 или 24 часа.

## Из чего состоит

| Часть | Где лежит | Что делает |
|---|---|---|
| Сайт чата | `index.html`, `app.js`, `config.js`, `firebase-config.js` | Интерфейс, вход, сообщения |
| Админ-панель | `admin/` | Список участников, владелец, журнал действий |
| Серверная часть входа | `backend/index.py` | Функция Яндекс Облака (Python 3.12): проверка входа Яндекс ID, выдача токена Firebase, подписанные ссылки на файлы, отправка уведомлений |
| Уведомления | `firebase-messaging-sw.js` | Service worker для уведомлений в браузере |

## Что нужно для запуска

1. **Firebase**: проект с Realtime Database, Authentication (Google) и Cloud Messaging. Правила базы берутся из админ-панели.
2. **Яндекс**: приложение на oauth.yandex.ru (адрес сайта в Redirect URI) и функция в Яндекс Облаке за API Gateway.
3. **Переменные окружения функции** (в коде их нет):
   - `FIREBASE_SA_JSON` ключ сервисного аккаунта Firebase
   - `FIREBASE_DB_URL` адрес Realtime Database
   - `OWNER_EMAIL` почта владельца (на случай, если в базе ещё нет записи владельца)
   - `S3_BUCKET`, `S3_KEY_ID`, `S3_SECRET` бакет и ключи Object Storage для файлов
4. **Заполнить конфиги**: `firebase-config.js` (параметры Web-приложения Firebase), `config.js` (ID приложения Яндекс, адрес API Gateway, VAPID-ключ).
5. **Опубликовать** статический сайт на любом хостинге (например, GitHub Pages) и добавить его адрес в разрешённые домены Firebase Authentication.

## Безопасность

- Секреты в репозиторий не попадают: `.gitignore` исключает ключи сервисного аккаунта и файл со списком почт.
- Правила базы проверяют, кто может читать и писать. Писать сообщение можно только от своего имени, длина текста ограничена.
- Текст сообщений выводится через экранирование, скрипты в сообщениях не выполняются.

## Что известно и не доделано

- Проверка входа на сервере идёт без проверки отзыва токена (`check_revoked=False`). Отозванный вход действует до часа.
- Уведомления может вызвать любой участник, ограничения частоты нет.
- Для работы с персональными данными в России хранение должно быть на территории РФ, см. описание для покупателя.
